# Changelog

All notable changes to the Chain2Pay WooCommerce plugin are listed here.

## 2.3.0

Current public release. The installable archive is attached to the
[v2.3.0 release](https://github.com/chain2pay-is/chain2pay-woocommerce/releases/tag/v2.3.0)
and is the same file that merchants download from the Chain2Pay dashboard.

- One WooCommerce payment method per supported provider, plus a hosted
  multi-provider checkout and a custom-provider method (see
  `README-custom-provider.md`).
- Support for the WooCommerce block checkout.
- Order status updated from the signed Chain2Pay callback.

The source in this repository is the unpacked content of that archive.
