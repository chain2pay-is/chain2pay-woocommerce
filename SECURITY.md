# Security policy

## Reporting a vulnerability

Please report security issues privately to **support@chain2pay.is** with the
subject line `Security report`. Do not open a public issue for a vulnerability.

Include, when you can:

- the plugin version and your WooCommerce and WordPress versions;
- the steps needed to reproduce the issue;
- what an attacker could do with it.

We acknowledge reports by email and keep you informed until the issue is fixed.

## Supported versions

Only the latest release published on this repository and in the Chain2Pay
dashboard receives fixes.

## Verify what you install

Install the plugin only from the Chain2Pay dashboard or from the releases of
this repository. The official domains are listed at
https://chain2pay.is/official-domains.
