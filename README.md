# Chain2Pay for WooCommerce

Official WooCommerce plugin for [Chain2Pay](https://chain2pay.is), the card-to-crypto payment gateway operated by Isthmus Business Group S.A.

The plugin adds Chain2Pay payment methods to the WooCommerce checkout. The buyer pays through a third-party on-ramp provider, and your store is notified when the payment is confirmed.

## Install

Step 1. Download `Chain2Pay-V2.3.0-WooCommerce.zip` from the Releases page.

Step 2. In WordPress, open Plugins, Add New, Upload Plugin. Choose the ZIP file and activate the plugin.

Step 3. Open WooCommerce, Settings, Payments. Enable the Chain2Pay payment methods you want and enter your Chain2Pay API key.

Your API key is in the merchant dashboard at https://dashboard.chain2pay.is.
